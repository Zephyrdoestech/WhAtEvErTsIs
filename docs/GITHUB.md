# GITHUB

## Commit Message
- naming convention: `<content-type>: <short description>`
- commit after every implementation

## Branching
- naming convention: `<developer-name>: <short-description>` (if branch exists already, do not make one but just checkout to their specified branch; if the branch contains their name, then thats their specified branch)
- branch when a developer starts doing something, make sure you branch them to their specified branch

## Merging and Conflicts
- naming convention: `<developer-name>: <implemented features separated by comma> merged from branch <branch>`
- merge after the developer say `merge`
- resolve any conflicts on your own, make sure to maintain the implemented features

## Contributors
- contributors are developers provided only
- do not include yourself as the developer

## IMPORTANT!!!
- read all the commit message history and check their naming conventions for reference.
