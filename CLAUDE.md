# Instructions for AI assistants

This repo is a 5-person hackathon project. Each developer has their own roadmap file:
`roles/KYLE.MD`, `roles/SYOS.MD`, `roles/RICKS.MD`, `roles/DIN.MD`, `roles/DAR.MD`. Shared rules and contracts are in `TEAM.MD`.

1. Find out which developer you are helping. If they haven't said, ask before doing anything.
2. Read `TEAM.MD` and that developer's file, then follow the "Rules for AI assistants" at the top of their file.
3. **Do one task at a time** (the first unchecked one, unless they name another), then stop and wait for the developer.
   Only do several tasks in one go when the developer explicitly asks for it.
4. Only edit files that developer owns. If something else needs changing, tell them who owns it.
